`estimation.method: em` now covers every model MAP can fit: ECM blocks (a few BFGS steps on the expected complete-data log-likelihood, accepted only when `Q` increases) for covariate links, irregular steps, tied/ordered parameters and families without a closed-form `m_step` (Student-t); `estimation.em.tempering` (deterministic annealing), `estimation.em.ecm.inner_iter`, `estimation.em.warm_start_from: map`; `FitResult.diagnostics["em"]` lists closed-form / ECM per block; `expanded_estep(..., keep_per_t=True)`; EM-vs-MAP parity table `docs/generated/em_parity.md`.
