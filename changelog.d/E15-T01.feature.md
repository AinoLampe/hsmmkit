`hsmmkit.online`: `ExpandedOnlineFilter` (`OnlineFilter`) with a jitted single-step `update`, `update_many` (scan), warm start from an offline forward pass and `update_from_time`; `OnlineState` with `save_state` / `load_state` guarded by `spec_hash`; `OnlineCovariatePreparer`. The filtered probabilities and the running log-likelihood equal the offline forward pass bitwise: the offline scan now calls the shared `forward_step`, and `Posterior.regime_filtered` is evaluated row by row. The `online` gate row is removed (`online.lag` / `online.alerts` stay gated).
