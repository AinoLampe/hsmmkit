The configuration schema (`schema_version: 1`) now contains every Part II key (sequences, labels, topology, left-censoring, per-state durations, mixtures, full covariance, `estimation.method`, `online`, `evaluation.cv`/`grid`); keys whose feature has not landed validate but are rejected at model build by `hsmmkit.config.gates` ("not available before <ticket>"). New preset registry with `hsmmkit presets list|show|write`, the core presets `core/segmentation_gaussian_ltr` and `core/two_regime_gaussian`, `hsmmkit config-schema --config-class`, and the `labels` init name (gated). `evaluation.backtest` and `forecast.covariate_forecaster` became optional (defaults: none / `freeze`).
