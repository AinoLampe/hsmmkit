`ObservationSet` is now domain-neutral (`series_names`, `values`, `source`, `meta`, optional `times` and `sequence_ids`; `CovariateSeries.provider` is `source`). New sources `numpy`, `pandas`, `csv` and `parquet` (`regimekit.data.sources`, `load_data`), time-less data under the `steps` clock, and the `source_contract` suite. Finance code reads the old names through `regimekit.finance.views.price_view`.
