# regimekit

JAX-based Hidden Semi-Markov Model framework for market-regime detection and probabilistic return
forecasting.

Built ticket by ticket from the specification in `spec/`; see the [Guide](guide/install.md) to get
started, the [Math](math/parameters.md) pages for the governing formulas, and the
[Architecture decisions](adr/index.md) for why things are built the way they are.

Status: pre-0.1.0, under active development.
